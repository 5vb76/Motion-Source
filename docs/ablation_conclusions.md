# 已完成的推理阶段组件消融

统一使用 Molmo2 MoSDeR 的 R checkpoint，固定权重，在完整 val1200 上进行推理干预。

|设置|四状态Acc|Camera Acc|Object Acc|解析失败|
|---|---:|---:|---:|---:|
|完整模型|84.08%|98.17%|85.42%|4/1200|
|共同全局池化|50.92%|98.00%|51.33%|5/1200|
|关闭Object分支|47.67%|97.17%|49.25%|3/1200|
|固定来源门控|7.83%|12.75%|7.92%|1046/1200|
|关闭Camera分支|0.33%|0.42%|0.33%|1195/1200|

主分析：共同池化下降33.17个百分点，95% CI [26.85,39.07]；关闭Object下降36.42个百分点，95% CI [31.28,41.82]。均为2000次来源分层、采集组配对bootstrap。相机判断保留、目标判断受损且格式正常，支持目标分支和来源池化分工的组件依赖性。

固定门控与关闭 Camera 分支导致严重格式失稳，其准确率变化包含输出格式的影响。以上实验衡量固定权重下的组件依赖，未比较重新训练的单分支模型。
