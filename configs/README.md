# 训练参数

| 文件 | 用途 |
| --- | --- |
| `molmo_2048.json` | Molmo 的 2,048 条 QA 训练参数 |
| `nvila_2048.json` | NVILA 的 2,048 条 QA 训练参数 |
| `nvila_5701.json` | NVILA 完成 2,048 条后，对剩余 3,653 条 QA 继续训练的参数 |

这三个文件没有本地绝对路径。模型权重、解释器、数据和外部源码路径在 Python 入口与数据集配置中，具体位置见[本地路径配置](../docs/LOCAL_PATHS.md)。运行器还需要完整的 `PLAN.json` 及相应输入文件。
